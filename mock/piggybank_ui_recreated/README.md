# PiggyBank UI — high-quality canvas recreations

This package contains 26 individually separated, high-resolution UI reference canvases recreated from the supplied PiggyBank mock-up.

## Contents
- `png/` — 26 high-resolution PNG exports for quick preview and use in design boards.
- `svg/` — the same 26 screens as scalable vector artwork. Text, panels, charts and most decorative elements remain editable.
- `source/` — the original supplied reference image.
- `contact_sheet.jpg` — overview of all 26 recreated canvases.
- `manifest.json` — names, descriptions and output dimensions.

## Notes
- The five clipped panels at the top of the source and five clipped panels at the bottom have been reconstructed as complete reference panels rather than preserved as partial crops.
- The visual language follows the original: dark blue-green navigation, fresh green actions, soft mint accents, white cards, rounded corners and a friendly piggy-bank mascot.
- These are high-quality visual references, not production-ready UI code, a functioning application or a Figma source file. SVG files can be imported into many design tools and inspected/edited as vector artwork.
