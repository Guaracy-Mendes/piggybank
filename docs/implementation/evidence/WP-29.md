## Delivered behavior

1. **Fail-closed runtime configuration (SEC-04).**
   - Any non-local profile refuses to start.
   - Secret files are validated at startup: the session key ring must parse; the issuer admin secret needs 16+
     characters and the metrics token 32+, and both must not be readable by group or others. Values are never
     logged.
   - Migrations are locked by checksum and expand-only (`make migrations-check`, `contracts/migrations.lock.json`,
     66 locked).
2. **Local CI-equivalent pipeline (NFR-12).** `make ci` (`scripts/ci.py`) runs the gated stages in sequence and writes
   sanitized `.local/ci/<UTC>/evidence.json` plus per-step logs. No remote CI host is configured (DEC-05).
3. **Observability and paging (NFR-10).**
   - Token-gated Prometheus `/metrics`: request counts and latency by route template, plus operational gauges
     including unbalanced journal batches.
   - Durable page tick with primary delivery and escalation to the secondary.
   - The on-call roster has recorded history, and only a paged person can acknowledge, which is audited.
   - The staff **Operations monitor** shows pages and the roster.
4. **Recovery tooling.**
   - Backup and restore drill with invariant and chain-head equality, serving the same balance from an API on the
     restored copy.
   - Rolling upgrade, rollback and forward-recovery runbook.
