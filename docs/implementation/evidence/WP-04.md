# WP-04 — Identity integration evidence

Verified locally on 2026-10-23 using Keycloak 26.5.0, PostgreSQL and the locked Rust/Playwright workspace. `make app-check`, `make test-identity` and `make test-browser` passed. The existing eight domain/health tests and real migration/privilege integration test also passed after adding identity migrations.

Implemented separate customer/workforce realms, distinct client/audience contexts, service credentials, native public-client PKCE configuration, issuer/RS256/JWKS validation, bounded key refresh, code/PKCE/nonce/state validation, opaque BFF sessions, server-held tokens, CSRF/origin checks, refresh leases, logout and attributable session records. Browser application clients do not enable password grants. Access-token lifetime is bounded to preserve the revocation objective. Factor/security management routes to the authenticated issuer account console; the complete recovery/abuse qualification remains WP-28.

Actual issuer integration tests exercised successful customer/workforce authorization-code login, wrong-audience/unsigned-token denial, service/workforce separation, rejected application password grants, forged callback state, missing/wrong-origin CSRF denial, refresh, provider-side disable/logout revocation, full logout and generation/acceptance of a new real issuer signing key. The temporary key provider was removed and the synthetic user restored after the test.

Playwright 1.64.1 drove a real Chromium login, verified HTTP-only bank cookies, denied customer-to-workforce access, rejected missing CSRF, and invalidated the local session on authorized logout. The Python HTTP harness separately emulates loopback cookie trust; application cookie settings are not modified for tests. Credentials/tokens and authentication traces are excluded from test output/artifacts.

Only the synthetic loopback profile is enabled. Production TLS, key/storage protection, approved authenticators, identity-provider operations and full recovery policies remain later qualification gates. No customer banking or financial authority is granted merely by authentication.
