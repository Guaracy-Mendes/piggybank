Verified locally on 2026-10-23 with the locked Rust workspace. `make app-check` passed with warnings denied. `make test-unit` passed eight tests with no ignored tests.

Implemented typed UUID identities, exact signed integer money with canonical string transport, explicit synthetic currency/scale, checked arithmetic, positive-command validation, injectable clocks, trusted actor/delegation context, recursively canonical SHA-256 request/approval fingerprints, and a versioned event envelope/schema. Executable application/account/payment transitions cover the corresponding UML states.
