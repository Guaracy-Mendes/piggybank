# WP-14 — Owned cases and independent review evidence

Verified locally on 2026-10-23 with eleven real PostgreSQL integration tests, HTTP ingress/contract tests and warning-free Rust/generated-client checks. Cases deduplicate by kind/origin, retain resource and evidence references, assign a responsible queue, expose deadlines/next actions and support individual claiming, information requests, proposals, withdrawal, independent decisions and escalation. The worker creates blocking control exceptions and escalates overdue cases.

Current staff roles and queue relationships are both required. An unrelated reviewer with the same global role could not inspect a case. Another login for the maker's canonical person could not approve; revoked authority failed. Only current provider REVIEW evidence can receive an independent synthetic manual clearance/decline. Hard denial and conflicting original ALLOW evidence cannot be cleared through that path. Final original provider evidence remains immutable, with separate case/decision provenance. Payment cases cannot be disposed as a service resolution or used for journal edits; escalation leaves an owned next action.

Customer information submission verifies ownership before object creation, preserves immutable restricted objects and uses a details-bound request receipt. Repeated content returned the same evidence reference, changed content conflicted, and foreign customers were denied. Staff evidence download rechecks current case relationship/role, reference membership and object digest, and records access. Customer summaries expose permitted generic next steps without screening labels or analyst evidence. Duplicate decisions/automatic case creation were stable; overdue escalation was idempotent. Audit chains verified.

The actual customer/staff HTTP routes and generated client now describe 23 route patterns, including queue/detail/actions, customer information and restricted evidence retrieval. Browser workbench integration follows WP-19; real operational staffing and production policy remain external launch inputs.
