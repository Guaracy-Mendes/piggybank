# WP-09 — Events and worker evidence

Verified locally on 2026-10-23 with `make test-integration`, `make test-events` and `make app-check` against real PostgreSQL and persistent JetStream.

Every module has its own outbox/inbox, aggregate cursor, dead-letter and replay records. Platform operation state/version and its event commit together. Tests proved rollback publishes nothing, committed events survive before publication, consumption commits receipt/effect atomically, and broker redelivery after a missing acknowledgement creates no second projection effect. Stable event identities are retained independently of the broker deduplication window. Producers serialize undelivered versions per aggregate; consumers quarantine gaps, conflicting identities, unsupported schemas and malformed payloads. Raw malformed deliveries are retained by digest. Replay uses the original envelope, is gated by current Controls entitlements and records requested/applied/pending evidence; it has no external financial submission handler or notification side effect.

The separate worker now dispatches registered leased jobs, relays each owned outbox and runs the durable Data operation consumer. Batches/in-flight deliveries are bounded. A real process restart test reclaimed an abandoned fenced lease, completed the original diagnostic job, published three ordered operation facts and recovered the same persisted projection after a second restart. A repeated command returned the same operation and one original job. Unregistered handlers retry and eventually require review rather than reporting success.

This proves local process/database/broker semantics, not clustered broker durability or production network isolation. The diagnostic handler has no customer or financial effects. Domain-specific consumers and notification suppression are added with their owning packages. Gaps require authorized repair; no automatic financial resend is inferred from replay. Retention is a seven-day synthetic local stream setting, not an approved production retention policy.
