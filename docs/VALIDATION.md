## Reproduction

```sh
make docs
```

This renders previews into a staging directory, publishes them only after successful validation, refreshes the Markdown gallery, checks local documentation links/IDs/coverage, then checks all PlantUML syntax. The render/check scripts use Python's standard library; no application dependencies or cloud credentials are required. The official PlantUML JAR is checksum-pinned and cached outside tracked artifacts.
